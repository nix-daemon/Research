## Structure for a future experiment

When an experiment exists, keep its question, implementation, and results together. Document:

1. The question, scope, and hypothesis.
2. Environment versions and reproduction steps.
3. Baselines, controls, and observed results.
4. Analysis, limitations, and source references.
5. What was personally implemented and any external foundations.

Keep completed writing, work in progress, and proposed experiments clearly distinguished. Add an experiment directory when there is actual material to put in it.
